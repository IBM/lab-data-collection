
# 3D print supports

The files are ready to print. The camera supports were 3D-printed in Onyx plastic, a micro-carbon-fiber-filled nylon, and assembled with screws and springs that form hinges and allow angle adjustment, as shown in the figure. Depending on the camera, an alternative version of the fixed-camera support may be used.
