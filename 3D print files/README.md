
# 3D print supports

The files can be used directly for the print. Camera supports were 3D printed in Onyx plastic (micro carbon fiber filled nylon) and completed with screws and springs that make hinges and allow the regulation of angles as shown in figure. Depending on the camera used, it an alternative version of the fixed camera support can be used.
