## Prospective analysis results

The results of the prospective analysis are contained in the csv file. The videos name are reported in the column `filename_video` and the relative JSON file containing the predictions per video in the column `source_file`.
In the column `source_file_per_video` the name of the JSON is repeated for every video. 

Given the low amount of data, the outcome was double checked manually.
Check Supporting information for more details.
